How speculative parallel works

Conversation PII detection and conversation summarization start together. If PII is found, the first summary is discarded and the redacted transcript is summarized again. Unsafe speculative summaries are never returned or rendered by this backend — though the speculative call does send the un-redacted transcript to Azure. Both tasks are asynchronous jobs polled at one-second intervals, so every operation's latency has a poll-cadence floor.
